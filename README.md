"Canada NPP data compilation.csv", "NPP data compilation.csv", and "Other Reactor Releases.xlsx" contain release data/estimates for different nuclear reactors. 
"Tritium_Analysis_Clean.ipynb" is the Jupyter notebook used for analyzing the data.
"app.py" is used for running the Gaussian Plume modeling (uses calc_sigmas.py and gauss_func3) and hydrological modeling.
